The fine-grained, step-by-step checklist for feature parity with
https://github.com/jellyfin/jellyfin (server side). Milestones and grouping
live in [[file:roadmap.org][roadmap.org]]; conventions (states, priorities,
tags) in [[file:methodology.org][methodology.org]]. Every item here should be
flipped to DONE in the same commit as the code that implements it.
