The fine-grained, step-by-step checklist for feature parity with
https://github.com/jellyfin/jellyfin (server side). Milestones and grouping
live in [[file:roadmap.org][roadmap.org]]; conventions (states, priorities,
tags) in [[file:methodology.org][methodology.org]]. Every item here should be
flipped to DONE in the same commit as the code that implements it.

* 1. Server core and HTTP API :feature:
** TODO System endpoints
   - [X] =GET /System/Info/Public= (ServerName, Version, deterministic 32-hex Id)
   - [ ] =GET /System/Info= (authenticated: full info)
   - [ ] =GET /System/Configuration= and update
   - [ ] =POST /System/Restart= / =POST /System/Shutdown=
** TODO OpenAPI/Swagger spec generated from code + =/api-docs= UI
** TODO CORS handling
   - [X] OPTIONS preflight (204) + permissive CORS headers on every response
   - [ ] CORS configurable per config
** TODO WebSocket endpoint (=Socket=) for server events
** TODO Error model
   - [X] AppError (NotFound/BadRequest/InternalError) -> 404/400/500 in the router; exceptions caught as 500
   - [ ] request IDs + consistent JSON error body
** TODO Graceful shutdown; finish in-flight requests
   - [X] health endpoint (=GET /healthz=)
** TODO Config: file (JSON/YAML) + env vars + CLI, with validation and defaults
   - [X] env vars + defaults (MEDIA_SERVER_PORT, MEDIA_LIBRARY_PATH, FMS_STATE_DIR)
   - [ ] config file, validation, CLI arg

* 2. Libraries and scanning :feature:
** TODO Library model: media folders (=GET /Library/MediaFolders=, add/remove/update)
** TODO Library types: movies, shows, music, books, photos, mixed, home videos
** TODO Virtual folders / path mapping per library (multiple paths per library)
** DONE Scanner: recursive walk, media-extension filter, mime map
** DONE Library API: GET /library, GET /library/:id, POST /library/rescan
** DONE [#A] Stable IDs via acid-state (see [[file:acid-state.org][acid-state.org]]) - monotonic ids persisted across restarts
** TODO Symlink policy (follow/ignore, circular detection) and race-safe scanning
** TODO Incremental scan + filesystem watching (inotify/FSEvents)
** TODO Scan progress reporting via WebSocket; scheduled scans (tasks)
** TODO Multi-version media (multiple files for one movie, version selection)
** TODO Extras: trailers, behind-the-scenes, deleted scenes, theme songs/videos
** TODO Playlists and box sets as first-class virtual items

* 3. Metadata :feature:
** TODO Item model fields: overview, genres, tags, studios, persons, production year, premiere date, ratings (critics/community), community rating, official rating, run time, series linkage (series/season/episode), index numbers

** TODO Remote providers: TMDB, OMDb, TVDB, AniDB, MusicBrainz, AudioDB

* 6. Playback and streaming :feature:
** TODO Direct play
   - [X] =GET /stream/:id= with byte-range support (200 full / 206 + Content-Range; malformed -> 200 full; unsatisfiable -> 400)
