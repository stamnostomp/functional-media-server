* functional-media-server

A media server inspired by [[https://github.com/jellyfin/jellyfin][Jellyfin]], written in Haskell
and built with Nix via cabal2nix.

All project tracking lives in this =docs/= folder as org files. The
methodology (module system, acid-state, task tracking) is adopted from the
sibling repository =../functional-media-server=.

** Documents

- [[file:roadmap.org][Roadmap]] — Jellyfin feature parity + backlog, as org TODO items
- [[file:todo.org][TODO]] — step-by-step checklist for Jellyfin feature parity
- [[file:methodology.org][Methodology]] — how we track work in org (TODO states, sections, tags)
- [[file:modules.org][Module system]] — monadic modules: AppM, Module/Route, capability classes
- [[file:acid-state.org][acid-state]] — persistent, stable library IDs
- [[file:architecture.org][Architecture]] — principles, module layout, tech choices, data flow
- [[file:dev-setup.org][Dev setup]] — git / nix / cabal2nix workflow

** Quick start

#+begin_src sh
nix develop          # dev shell: ghc, cabal, cabal2nix, haskell-language-server
nix build            # build the fms executable through cabal2nix
nix run .#default    # run it
cabal test           # inside the dev shell, run the test suite
#+end_src
