#+AUTHOR: stamnostomp
#+STARTUP: overview

How to work on this project day to day.

* Prerequisites

- Nix with flakes enabled (=nix-command flakes=)
- git

Everything else (ghc, cabal-install, cabal2nix, haskell-language-server)
comes from the Nix dev shell.

* Common commands

#+begin_src sh
nix develop                 # enter dev shell
nix build                   # build ./result (the fms executable)
nix run .#default           # build + run
nix flake check             # evaluate all flake outputs
nix flake update            # bump nixpkgs
cabal build all             # inside dev shell: local build in dist-newstyle/
cabal test                  # run the test suite
cabal run fms               # run the server locally
ghc -e ... / hls            # editor integration via haskell-language-server
#+end_src

* cabal2nix workflow

The flake uses =haskellPackages.callCabal2nix "functional-media-server" ./.\;=
so the =.cabal= file is re-read on every evaluation — after adding a
dependency to the .cabal file, just rebuild; no manual regeneration step is
required.

If you ever want a static Nix expression (e.g. to vendor or diff it):

#+begin_src sh
nix develop --command cabal2nix . > default.nix
#+end_src

* Git workflow

- Work on branches, merge to =main=.
- Commit messages: short imperative subject, details in the body.
- *Commit after each major step*: every time a [[file:todo.org][todo.org]] /
  [[file:roadmap.org][roadmap.org]] item (or a coherent chunk of one) lands,
  commit it immediately as a small, focused commit. Never leave a major step
  uncommitted.
- Don't commit =dist-newstyle/= or =result= (see .gitignore).
- Keep the roadmap in [[file:roadmap.org][docs/roadmap.org]] up to date in the same
  commit as the work it describes; follow the conventions in
  [[file:methodology.org][docs/methodology.org]] (TODO states, sections, tags).

* Push/signing node

Node one is the dedicated GitHub push/signing node. Use node-1 for GitHub
pushes and SSH signing keys. GitHub auth/signing public keys are generated
there.
