#+TITLE: Architecture
#+AUTHOR: stamnostomp
#+STARTUP: overview

Design decisions for the Haskell media server. The module system and
persistence design are adopted from the sibling repository
(=../functional-media-server=) and specified in detail in
[[file:modules.org][modules.org]] and [[file:acid-state.org][acid-state.org]].
Update this file as decisions change; [[file:roadmap.org][roadmap.org]] tracks
what to build and when.

* Principles

- Pure core, effectful shell: domain logic (scanning, metadata merging,
  range parsing, transcoding decisions) is pure and testable; IO (HTTP,
  ffmpeg, disk) is pushed to the edges.
- Monadic module system: the app runs in =AppM = ReaderT AppEnv (ExceptT
  AppError IO)=; modules plug in as a =Module= record (name, init, routes)
  plus an mtl-style capability typeclass with an =AppM= instance. Adding a
  module never changes the core.
- Module state lives in a typed registry in =AppEnv= (=Map Text Dynamic=
  via =putState=/=getState=) under namespaced keys — the core never knows a
  module's state exists.
- acid-state for persistent library state (stable IDs across restarts and
  renames), replacing the earlier SQLite-first plan; SQLite remains the
  fallback for very large libraries.
- Nix is the source of truth for builds; cabal is for local iteration
  inside the dev shell. The flake translates the .cabal file with
  =callCabal2nix=.
- Docs-driven: every design lives in =docs/*.org= before code (see
  [[file:methodology.org][methodology.org]]).

* Key technology choices

| Concern      | Choice                                             |
|--------------+----------------------------------------------------|
| HTTP server  | warp + wai, custom Router over a [Module] list     |
| App monad    | mtl: ReaderT AppEnv (ExceptT AppError IO)          |
| Module state | typed registry: IORef (HashMap Text Dynamic)      |
| Persistence  | acid-state (library IDs/state); JSON files for stats |
| JSON         | aeson                                              |
| HTTP client  | http-conduit (TMDB/TvMaze)                         |
| NFO parsing  | xml-conduit                                        |
| Transcoding  | ffmpeg subprocess + HLS                            |
| Auth         | API keys / tokens; RBAC (milestone 5)             |

* Build / packaging

- =flake.nix= exposes =packages.default= (the =fms= executable, built with
  =haskellPackages.callCabal2nix=) and =devShells.default=.
- After editing the .cabal file, nothing needs regenerating for the flake
  (callCabal2nix re-reads it each evaluation). For a static =default.nix=,
  run =cabal2nix . > default.nix= inside the dev shell.
- System dependencies (ffmpeg, sqlite) will be added via =callCabal2nix ... { }=
  args or a package override when milestone 3 starts.
